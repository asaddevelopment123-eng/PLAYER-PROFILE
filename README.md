# Unity Player Profile System

A simple Unity C# project created to practice variables and data types.

## Concepts Used

- int
- float
- string
- bool
- char
- Debug.Log()
- Basic Unity scripting

## Features

- Player health
- Player name
- Player weapon
- Bullet count
- Player status
- Player rank
- Movement speed
- Mana

## Purpose

This project is part of my journey toward becoming a gameplay programmer.
